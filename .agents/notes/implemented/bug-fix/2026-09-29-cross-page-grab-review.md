# 跨番组页补集：钉住、错季诊断、尝试上限与出处

**日期**: 2026-09-29  
**状态**: implemented / bug-fix  
**触发**: PR #2 合并后的 Sourcery / Codex review；v0.5.1 的 `episode-available` 仍有四处边界问题。

PR #2 让缺集到发布时间覆盖播出日的备用番组页查找，但备用查找必须遵守以下约束：

- `pinned` 中有 `mikan_id` 且值非空时，人的指定页是唯一抓取来源。选主页时直接用它，缺集时也不搜索备用页；缓存和标题搜索不能覆盖它。
- 主页面上声明了别季的同集号只用于诊断。它不能代替有效候选，也不能挡住按播出日期搜索备用页。找不到有效发布时仍沿用原有错季提示。
- 四页上限按**尝试过的页面**计，包含主页面和拉取失败的备用页。失败仍记录日志，并出现在长期缺集的 `mikan_pages` 证据中。
- 备用页候选被选中时，Finding 的 `evidence.mikan_id` 记录该候选所在页；执行器将同一份 evidence 写入出处账本。主页候选仍记录主页 id。

回归测试分别覆盖上述四种情况。既有 `_plausible_for` 的播出日期闸、`_slot_in_season` 的季号偏移换算、超过 7 天才报告没有发布的缺集规则均保持原样。
