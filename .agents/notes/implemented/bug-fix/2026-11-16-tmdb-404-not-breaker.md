# 一个 TMDB 条目 404 让整轮停问 TMDB：404 只跳过这一部

**日期**: 2026-11-16
**状态**: implemented / bug-fix
**触发**: 学生会也有洞！第 7 集 11/15 播出，钉了 `tmdb_id=283938` 之后 dry-run 仍不抓。根因在别的番：
凭物语（327851）、历物语（328198）的 TMDB 条目被并进「物语系列」（46195），每轮回 404。

## 现象

`scan._tmdb_meta` 的熔断（`net["broken"]`）对所有异常一视同仁：扫描顺序里排在前面的一部番 404，这一轮
其余的番都不再问 TMDB、沿用上次的标题。刚钉上身份、没有历史标题的番于是每轮被 `tmdb-identity`
暂停改名和抓取——一部失效的条目拖垮了整轮。

## 做法

HTTP 404 是"这一个条目没了"，不是"TMDB 连不上"：只这一部沿用旧值，并在日志里说清楚要去 sidecar 改钉；
超时、连不上、5xx 仍然熔断（与 `cache.season_episodes` 的口径一致：4xx 只是这一个键的答案）。

## 测试

`tests/test_scan_tmdb_404_not_breaker.py`：404 只跳过那一部、别的番照问；503 与 ConnectError 仍熔断。
去掉修复后第一条变红。

## 后续

凭物语 / 历物语的身份要改钉到 46195 的对应季；季号对不上会误抓，单独处理。
