# 字幕语言后缀认不出 JPSC/JPTC；「规制解除 / 限制解除」拿不到无删减加分

**日期**: 2026-11-16
**状态**: implemented / bug-fix
**触发**: 生产两件事。2026-11-10 健康报告 ok → warn（10 个文件停在发布名）：赛博朋克：边缘行者的
VCB-Studio BDRip 每集带 `.JPSC.ass` / `.JPTC.ass`；2026-11-09 学生会也有洞！换无修版时，悠哈璃羽的
「规制解除版」和合并发布里的「限制解除版」文件在偏好里都是 0 分。

## 现象

- `naming.subtitle_lang_tag` 只认 `sc/tc/chs/cht/scjp/tcjp/…`，不认语言在前的 `JPSC/JPTC`。简繁两份
  都被算成"无语言标记"，目标名都是 `S01E0x.ass`：第一份改过去，第二份每轮「集位被占」跳过，永远停在发布名。
- `.agents/preferences.json` 的「无删减」只列了 `无删减/無修正/uncensored/…`，字幕组对无修版的常用说法
  「规制解除 / 規制解除 / 限制解除」不在里面。判重排序里无修版拿不到 +100，能不能留下全看别的偏好碰巧够不够。

## 做法

- 语言后缀改成一条正则：`(jp)?(sc|tc|chs|cht|gb|big5)(jp)?`、两个字母的语言码（可带 `jp`）、`zh-xx(xx)`，
  原样返回（大小写不改），同一集的简繁两份落到两个不同的名字。
- 「无删减」的 `any` 加上三个词，权重不变。

## 测试

`tests/test_subtitle_lang_and_uncut_words.py`：12 种后缀识别、3 种不该识别、VCB 简繁一对落到两个名字、
三组"无修版 − TV 版"的偏好分差正好等于无删减的权重。
