# 让 agent 看不见问题的三个缺陷

一次 `evolve` 的产出不是新规则，而是三处"它自己看不见"的地方。
起点只有一条线索：演进器报了个「⚠️ ×30 反复失败」。

## 1. 失败报告器在翻旧账

`find_failure_patterns` 扫的是只增不删的审计日志，**没有时间窗口**。
那 30 次失败发生在 2026-08-17，问题当天就修好了，之后两周零失败，
可它照样每轮顶着"反复失败"出现。

而且它按**条目**计数：同一轮里 30 个文件因同一原因失败，被报成 30 次。
那是一次事件，不是 30 次。真正说明"规则有问题"的是同一原因**跨批次**复发。

改成 14 天窗口 + 按 `run_id` 计数，输出「N 个批次 / 共 M 次」。

## 2. 扫描把文件整个丢掉

顺着那条失败往下查，发现根因在 `scan.build_state` 的「来源 2」：

```python
if t is not None and Path(t.get("save_path") or "") == p.parent:
    continue                          # 已由来源 1 覆盖
```

向上找父目录认领种子，对**多文件种子**是危险的——它的 `content_path`
就是季目录本身，于是该目录下每一个孤儿文件都被认领给它，
然后被这句"已覆盖"短路整个丢弃。

《住在拔作岛上的我应该如何是好？》因此只有 2 个文件对 agent 可见，
磁盘上实际有 15 个：8 个正片 + 6 个字幕**对所有规则不可见**，
既不报错也不处理。当初那 30 次改名失败也是同一个根：
文件带着错误的 hash 去改名，执行器正确地拒绝了
（"种子文件列表里找不到该文件"）。

修法：来源 1 已把本剧目录下所有种子的文件登记进 `covered`，
能走到来源 2 就说明这个文件不属于它们，别认领，按纯本地文件处理。

药屋没暴露这个 bug，是因为它一个种子都没有。

## 3. 演进器结构性地看不见字幕

`find_residue` 只扫视频：

```python
if f.is_incomplete or f.ext not in VIDEO_EXTS:
    continue
```

而 `unrenamed-file` 本来就同时管视频和字幕。于是"字幕解析不出集号"
这一类会永远报 `unparsable`、永远评不上盲区、永远没人能立规则去修。

纳入字幕后又撞上第二道闸：`_signature` 只掩数字、保留整个文件名，
`【全面限制 ver.】【配信限定 ver.】【青蓝岛 ver.】` × `简体/繁體`
把 6 个同类文件切成 6 个 `count=1` 的簇，被"单例不立规则"滤掉。
改成连括号内容一起抽象成 `…`，但纯数字括号保留成 `#`（集号是结构里
最有意义的一环）。6 个文件聚成 1 簇。

## 4. 模型在猜字段格式（同一次演进又炸出来的）

聚成簇之后，演进器终于提出了规则，却被影子验证以"一个都没命中"驳回。
规则语法完全正确，错在一个条件：

```json
{"field": "ext", "op": "eq", "value": "sup"}
```

`MediaFile.ext` 返回的是 `.sup`，**带点**。

根因是 `find_residue` 塞给模型的样本字典是**手写**的，
恰好漏掉了 `ext` / `has_torrent` / `torrent_progress` 这几个；
而系统提示词只给字段**名字**（`ext, filename, has_torrent, …`），
不给类型和格式。模型无从知道 `ext` 带点、`torrent_progress` 是 0–1
而非 0–100，只能猜，猜错就白烧一次调用。

改成 `{k: g(f, show) for k, g in _FIELD_GETTERS.items()}`——
样本直接从 DSL 的字段表生成，模型看到的是真实取值，从此不可能漂移。

（已上线的 29 条规则查过，0 条踩这个坑：影子验证在上线前都拦住了。
所以这不是正确性问题，是有效性问题——安全网在工作，代价是盲区补不上。）

## 共同点

2 和 3 是同一类：**agent 看不见的东西，它不会报告"我看不见"**。
一个表现为文件静静躺在库里，一个表现为演进器永远说"没有盲区"。
这类缺陷不会自己暴露，只能顺着一条可疑线索往下挖——
而那条线索（1）本身还是个会被噪音淹没的告警。

值得记的是：**能挖到底，是因为报错信息说的是实话**。
执行器没有"尽力改名"，而是拒绝并写下"种子文件列表里找不到该文件"。
那句话两周后仍然精确指向了根因。
