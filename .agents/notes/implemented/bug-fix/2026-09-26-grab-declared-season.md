# 抓取从别季的正片里抓特典位：声明的季号对不上就不是候选

**日期**: 2026-09-26
**状态**: implemented / bug-fix
**触发**: LAT-03。2026-09-06 13:51:42 / 43，辉夜大小姐想让我告白的特典位 S00E03、S00E04 被抓进了
`[澄空学园&雪飘工作室&LoliHouse] 辉夜大小姐想让我告白 第三季 / Kaguya-sama wa Kokurasetai S3 - 03 / 04`
（发布于 2022-04-26 / 05-07）——第三季的正片。库里多了 `Season 0/辉夜大小姐想让我告白 S00E03.mkv`、`S00E04.mkv`，
sidecar 的 S0 `have` 成了 `[1, 2, 3, 4]`。那是生产审计里仅有的两次 S0 抓取。

## 根因

- `EpisodeAvailableDetector` 按**裸集号**归拢候选（`by_ep[3]`）。声明的季号只用来**多加**一个按
  `season_offsets` 换算后的位置，原来的集号照样登记——于是 Re:Zero（`{"3": 50}`）的 `3rd Season - 08`
  同时是 S01E58 与 S01E08 的候选（测试复现：S01E08 也缺着时两处都抓）。
- 日期闸 `_plausible_for` 只拦"早于播出"（老番重新做种本来就晚），2022 年的第三季第 3 集对 2021 年播出的
  特典第 3 集是"合理的"。
- `season_layout_mismatch` 不看第 0 季。

## 做法（`grab._slot_in_season`）

候选先按**目标季**认一遍它落在第几集：

| 发布 | 目标是正片季 N | 目标是特典位（第 0 季） |
|---|---|---|
| 没声明季号（`- 03`） | 第 n 集 | 只有标着特别篇 / 番外 / 总集篇 / OVA / OAD / SP / Special（或 `S00Exx`）才收 |
| 声明第 N 季 | 第 n 集 | 同上：标着特典字样才收（`第三季 OVA` 是挂在第三季名下的特典） |
| 声明第 M 季、`season_offsets` 有 M | `n <= 偏移` 时第 n + 偏移 集，否则第 n 集（与改名 `_slot_from` 同一口径），**不再**同时登记第 n 集 | 同上 |
| 声明第 M 季、没有换算 | **不是候选** | 同上 |

- 声明的季号按标题里 ` / ` 分开的每一段各认一次（中文名写 `第三季`、英文名写 `S3` 的都算），`naming.declared_season`
  自己只看最后一段。
- 被排除的不悄悄跳过：一个候选都不剩时照旧报「只搜到 N 个明显属于别季的同集号发布，全部跳过」，
  `evidence.rejected_by_season` 写明每一条为什么（标的是第几季 / 不是特典），`rejected_by_date` 照旧；有候选时
  这两样也进抓取发现的 evidence。
- 特典位的"没有特典字样就不收"比 LAT-03 的不变式多走了一步：同一页上别的组写
  `Kaguya-sama wa Kokurasetai - Ultra Romantic - 03`，`Ultra Romantic` 就是第三季的副标题，不声明季号，只看季号
  拦不住它。历史上 S0 的抓取只有这两次，全是错的。

## 行为变化要知道的

- 入间同学入魔了！：桜都把 TMDB 的第四季标成「第3季 / 3rd Season [20]」（生产审计里这个组的发布被抓了 30 次）。
  现在它们不是第四季的候选，第四季改从 Nix-Raws（`S04E20`）/ LoliHouse（`S4 - 23`）这类标对了的发布里挑；
  只剩桜都时报「明显属于别季」。要收桜都的，在 sidecar 里登记 `season_offsets: {"3": 0}`（第 3 季换算进来、集号不变，
  改名的 `_slot_from` 同样认它）。
- Re:Zero（`{"2": 25, "3": 50, "4": 66}`）、药屋（`{"2": 24, "3": 48}`）照旧换算，只是不再额外登记原始集号。

## 测试

`tests/test_grab_declared_season.py`：辉夜的真名字——特典位不收「第三季 / S3 - 03 / 04」（改之前抓了）、不收只写集号的
`Ultra Romantic - 03`、收 `第三季 / S3 OVA - 05`；入间的真名字——桜都「第3季」不是第四季的候选、只剩它时报别季、
登记 `{"3": 0}` 后照收；Re:Zero 的 `3rd Season - 08` 只落在 S01E58（改之前 S01E08 也抓）。
